# Bengaluru-House-Price-Prediction
House Price Analysis and Prediction using Python
Project Overview

This project analyzes Bengaluru housing data and predicts house prices using Python and Machine Learning.

Objectives

Analyze Bengaluru house prices.

Perform data cleaning and preprocessing.

Conduct Exploratory Data Analysis (EDA).

Perform statistical analysis and ANOVA testing.

Analyze location-wise average prices.

Build a house price prediction model.
